# AlgoPrep — персональный тренер по алгоритмическим интервью

Нативное Android-приложение (Kotlin, Jetpack Compose, Material 3). **Local-first**: работает без регистрации и без интернета, все данные хранятся на устройстве. Подробная спецификация — в [`docs/SPEC.md`](docs/SPEC.md).

## Что умеет

| Раздел | Суть |
|---|---|
| **Today** | День N/30, прогресс, теория, разминка, основная практика, повторения, разбор ошибок. У каждой задачи кнопка «Почему мне дали эту задачу?» |
| **План на 30 дней** | Базовый roadmap + адаптация: доли 70/20/10, рост доли слабых тем до 30%, перенос вчерашнего невыполненного, сдвиг/сжатие плана при пропусках (только по вашему выбору), ночной пересчёт |
| **Сессия решения** | Таймер по настенному времени (переживает поворот и убийство процесса), подсказки по одной, заметки, результат (как решил, уверенность, типы ошибок) |
| **Повторения** | Вариант SM-2, статусы NEW / LEARNING / REVIEW / MASTERED / FAILED_RECENTLY |
| **Статистика** | Серия, доля самостоятельных решений, тренд «улучшаюсь ли я», соблюдение плана, активность за 30 дней, темы (слабые/сильные), журнал ошибок |
| **Interview Task Bank** | Банк задач, импорт Import → Parse → Review → Save, дедупликация с объединением (упоминания/источники), откат импорта, экран Interview Data |
| **Напоминания** | Утро / вечер / повторение / серия; время задаёт пользователь; каждое можно отключить |
| **Mock Interview** | 45 мин / 1 задача или 90 мин / 2 задачи, обратный отсчёт, без подсказок, задачи из вашего банка |

Принципы: неизвестные метаданные остаются `null` (ничего не выдумывается); автоматический разбор только предлагает, решает пользователь; частоты в Interview Data считаются только по вашему импортированному набору и **не** прогноз; «AI» отсутствует — есть интерфейс `AiAssistant` и честный локальный fallback.

## Сборка

* Android Studio Ladybug (2024.2) или новее, JDK 17, Android SDK 35.
* `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.
* Тесты: `./gradlew testDebugUnitTest` (JVM), `./gradlew connectedDebugAndroidTest` (эмулятор/устройство).
* **minSdk 26** (Android 8.0): каналы уведомлений обязательны с этой версии, `java.time` без desugaring; покрывает подавляющее большинство устройств. target/compile SDK 35.

CI (GitHub Actions): `Build debug APK` — юнит-тесты, сборка, артефакт `algoprep-debug-apk`; `Instrumented tests` — androidTest на эмуляторе (API 30).

## Архитектура

Один модуль `:app`, границы — пакеты:

```
domain/        чистый Kotlin: модели, интерфейсы репозиториев, алгоритмы, use case'ы
  planning/    DayPlanner, TaskScorer, WeakTopics, AdaptivePolicy, PlanRescheduler, ReviewScheduler, SkillTracker
  importer/    парсеры (JSON/CSV/Markdown/TXT), TaskClassifier, DuplicateIndex, ImportPlanBuilder
  stats/ mock/ reminders/ hints/ ai/ usecase/
data/          Room (схема v1), DAO, репозитории, DataStore, сидирование из assets/seed
ui/            Compose-экраны + ViewModel (StateFlow), типобезопасная навигация
notifications/ background/   WorkManager: напоминания и ночной пересчёт
di/            Hilt
```

Данные приложения (темы, паттерны, roadmap, 63 стартовые задачи с подсказками) лежат в `app/src/main/assets/seed/` и `assets/hints/`. Схема Room экспортируется в `app/schemas/` и лежит в git (нужна для тестов миграций). Автоматического сброса БД нет: любое изменение схемы требует `Migration`.

## Как работает планировщик

1. День = theory + warm-up + error review (фиксированное время), остальное делится ≈ 70 / 20 / 10:
   * **spaced** (10%, до 30% при просроченных повторениях): повторения, иначе одна «смешанная» задача из уже изученных тем;
   * **weak** (20–30%): слабые темы вне тем дня;
   * **roadmap**: всё остальное — задачи тем дня.
2. Приоритет задачи — сумма именованных слагаемых с причиной каждого (не решалась +30, недавняя неудача +25, просрочено повторение +25…+35, слабая тема до +20, подходящая сложность до +15, частота в вашем импорте до +10 и только от 2 упоминаний). Причины сохраняются и показываются по кнопке «Почему?».
3. Roadmap не переставляется никогда; адаптация меняет только доли и объём.

## Импорт своих материалов

Файл (`.md .txt .json .csv`) или вставленный текст. Парсер сам разбивает документ на задачи (заголовки → горизонтальные линии → списки → абзацы), читает строки `Company:/Source:/Stage:/Level:/Date:/Difficulty:/Topics:` (EN и RU) и ссылки (**ничего не скачивается**). Перед сохранением вы видите каждую найденную задачу и правите любое поле; возможные дубли помечаются и решаются вами (объединить = ещё одно упоминание; ничего не удаляется автоматически).

## Что не сделано / ограничения

* Нет экспорта/импорта бэкапа и переключателя темы. `allowBackup=false`: при удалении приложения данные теряются.
* Нет реального AI: подсказки и классификация — локальные словари.
* Релизная подпись не настроена (CI собирает debug-APK).
* Дата старта плана выбирается из «сегодня / завтра / следующий понедельник», без календаря.
* Напоминания могут приходить с задержкой в несколько минут (Doze).
* Состояние мок-интервью переживает поворот и убийство процесса, но не выход из экрана по кнопке «Назад» (это сознательно, с подтверждением).
